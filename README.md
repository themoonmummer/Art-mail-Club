# Art Mail Club

Art Mail Club is a full-stack web application created as a college project.

The project provides an online space for an art community where users can explore artwork, interact with the community, manage their profiles, and access art-related features.

## Tech Stack

### Frontend
- React
- Vite
- React Router
- GSAP
- Lucide React

### Backend
- Node.js
- Express.js
- MySQL
- JWT authentication
- bcryptjs
- Multer

Requirements

Make sure the following are installed:

    Node.js
    npm
    MySQL

Running the Frontend

Open a terminal in the project root:

npm install
npm run dev

The frontend will normally run at:

http://localhost:5173

Running the Backend

Open another terminal:

cd backend
npm install
npm start

The backend will normally run at:

http://localhost:5000

Environment Variables

The backend uses environment variables for database and application configuration.

Create:

backend/.env

using backend/.env.example as a reference.

Do not upload the actual .env file to GitHub.

Example:

PORT=5000
CLIENT_ORIGIN=http://localhost:5173

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=
DB_NAME=art_mail_club

JWT_SECRET=your_secret_key

Use your own local MySQL password if your MySQL installation has one.
Database

The backend uses MySQL with the database:

art_mail_club

Make sure the database exists before starting the backend.

The database credentials are configured through backend/.env.
Testing the Backend

The backend provides a health-check endpoint:

http://localhost:5000/api/health

A successful response is:

{
  "status": "ok"
}

Production Build

To create a production build of the frontend:

npm run build

The generated files will be placed in:

dist/

Notes

    node_modules/ is excluded from Git and should be recreated using npm install.
    .env files containing secrets are excluded from Git.
    dist/ is generated by the Vite build process and does not need to be committed.
    The backend and frontend are separate applications within the same project.
